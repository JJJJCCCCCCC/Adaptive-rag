# Evidence120 · 定向补检与提前停止

2026-11-27 在 12 个虚构商户的 120 道冻结留出题上对照三种检索策略。先用另两家虚构商户的 24 道开发题验证运行和评分，再用相同脚本与配置处理整个留出集。留出集包含 30 道单文档题、40 道两文档题、30 道三文档题、10 道库内缺证据题和 10 道域外对照。资料中包含编号、条款名、别名、句内关联，以及已作废和仅供样品的干扰条款。

| 策略 | 可回答题通过 | 全样本通过 | 检索轮数 | 服务端总 Token |
| --- | ---: | ---: | ---: | ---: |
| 固定单轮 | 44/100 | 64/120 | 110 | 45,459 |
| 固定三轮 | 100/100 | 120/120 | 330 | 81,267 |
| 按证据补检 | 100/100 | 120/120 | 220 | 46,069 |

按证据补检相对固定单轮，在可回答题上增加 **56 个百分点**，商户聚类配对 bootstrap 95% 区间 **+44.4 至 +66.7 个百分点**。相对固定三轮，两组在 100 道可回答题上逐题同分，检索轮数减少 **33.3%**，模型 Token 减少 **43.3%**。留出集保留 **440 条唯一 DeepSeek Flash 回执**，实际合计 **172,795 Token**。这组样本两组逐题同分，观察到的配对差为 0，不能从零分歧推断其他语料或线上流量也等效。

## 计量范围

三组共享项目的 BM25、哈希向量、词面重排、首轮轨迹和最多三个最终证据片段。组件从已召回文档提取可查的关联词。固定三轮在没有可直接扩展的引用时，仍按其轮数预算调用模型改写并继续查找。按证据补检遇到终点或没有可继续的关联词时停止。模型为每个进入检索的策略生成独立答案。Token 来自服务端回复的输入与输出总量，计入该策略实际使用的改写和回答调用。

可回答题采用确定性的结构化评分，数值、中文单位和完整来源文档 ID 均正确才计通过。缺证据题检查拒答结构，域外对照由三组共享的合成商户范围检查处理。该域外检查无法代表产品路由在自然提问下的准确性。这是对明确引用链、规则化文档模板和候选补检策略的**受控组件实验**。它未替换项目默认 LangGraph 路径，没有测量生产侧的完整意图路由、端到端耗时、无结构隐式关联或通用问答质量。

与原方案相比，这轮使用同一严格规则评分结构化答案，未采用双人盲评。结果应和历史 [Evidence36](../../../docs/25-evidence-guided-study.md) 分开解读。Evidence36 使用不同资料、工作流和评分方式，历史结果原样保留。

## 复算与复跑

在仓库根目录安装项目依赖，设置 `PYTHONPATH=.`。第一条命令仅复算已保存的题库、回答和服务端回执，后两条在 `RAG_EVAL_MODEL_CONFIG` 指向包含 `DEEPSEEK_API_KEY` 的本地配置后执行。

```bash
PYTHONPATH=. python eval/benchmarks/evidence120/verify_audit.py holdout
PYTHONPATH=. python eval/benchmarks/evidence120/study.py holdout rerun --parallel 8
PYTHONPATH=. python eval/benchmarks/evidence120/package.py holdout rerun
```
